# 🧾 ProofBox - Build your evidence before you need it

> **"Everyday disputes generate evidence everywhere - WhatsApp, Email, Photos, Payments, Notes. When the dispute happens: People don't lack evidence. They lack an organised, chronological story that connects the evidence."**

---

## 🌟 Executive Overview

**ProofBox** is a specialized personal evidence-management web application engineered for ordinary people facing everyday disputes (tenants, freelancers, consumers, employees, small businesses). 

Instead of searching through 300 scattered WhatsApp messages, screenshots, and bank receipts when a conflict escalates, ProofBox provides the **preparation layer BEFORE legal intervention**.

### ⚖️ Real-World Legal Grounding
- **India**: Fully structured to generate Electronic Record Certificates under **Section 63 & 61 of Bharatiya Sakshya Adhiniyam (BSA), 2023** (formerly Section 65B of the Indian Evidence Act) with automated SHA-256 integrity digests.
- **United States**: FRE Rule 902(13) & 902(14) Certified Records Generated by an Electronic Process or System.
- **UK / Commonwealth**: Civil Evidence Act 1995 standard digital provenance compliance.

## 💻 How to Run the Web Application

### Option 1: One-Click Windows Launcher (`start.bat`)
Simply double-click [`start.bat`](file:///C:/Users/Gaurav%20Verma/.gemini/antigravity/scratch/proofbox/start.bat) or run from terminal:
```cmd
start.bat
```
**What `start.bat` does automatically:**
1. Verifies if Node.js/NPM or Python is installed.
2. Checks if `node_modules` exists; if not, automatically downloads and installs all dependencies (`npm install`).
3. Launches the local server at `http://localhost:3000`.
4. Automatically opens `http://localhost:3000` in your default web browser.
5. If neither runtime is installed, gracefully falls back to opening `index.html` directly in your browser.

### Option 2: Open Directly in Any Browser
Open `index.html` in your web browser:
```cmd
start index.html
```

### Option 3: Run with Local HTTP Server (Node.js)
```cmd
npm start
```
Then visit: `http://localhost:3000`

### Option 4: Run with Python
```cmd
python -m http.server 3000
```
Then visit: `http://localhost:3000`
